# Signature identity — sharecli

## Named signature element

**Hexagonal chevron stack** (“share + flow + dispatch”).

- Pulse-green `#3fb950` strokes on graphite `#0a0d12` panel
- Reads as a process rail: share → flow → dispatch
- Family: **Backbone-2** (Phenotype)

## Why it is unique

Not a generic terminal glyph or stock robot icon. The mark is **AI-coded** (hand-authored SVG), not AI-image-generated art. Motion identity is SMIL pulse + counter-rotating chevron — no JavaScript.
